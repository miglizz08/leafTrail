# Leaf Trail

Analisador de gastos pessoais, feito para uso próprio e, no futuro, para compartilhar com amigos e familiares.

## Status
Em desenvolvimento. Fase atual: layout das telas (HTML e CSS).

## Planejado
- Formulário para registrar gastos.
- Dashboard com o total e a tabela de gastos.
- Banco de dados MySQL.

## Tecnologias
Python, Flask, HTML, CSS e MySQL.
